1/ We built a delegation policy for our multi-agent stack. Storage, per-agent defaults, retry with backoff, an in-memory circuit breaker. All working. We reverted it the same day. 🧵

2/ The reason is the useful part: delegation between agents happens via a native LLM tool INSIDE the runtime — not an RPC our server can intercept. The policy had no insertion point. Four correct components, zero call sites.

3/ We'd built a governance layer for a call path that never passes through us. Keeping it alive was infrastructure without a consumer, so it went out with the migration that dropped its table.

4/ What we kept instead: the three conditions that would unblock it (runtime exposes spawn as an RPC / change the skill contract to an HTTP delegate_to / build our own spawning runtime). Those are cheap to re-check. The code was the expensive way to find them.

5/ Rule I'd write on the wall: when you're building governance for a system you don't fully own, the first deliverable isn't the policy — it's the proof that the policy can be enforced.

6/ Full write-up of all six delegation failures: https://micelclaw.com/blog/multi-agent-topology
